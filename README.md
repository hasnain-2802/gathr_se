# Gathr: Discover and Manage Events Across the City

Team BigTech: Yusra Sheraz, Fatima Arif, Hasnain Abbas, Hiba Faisal

## Stack
React (Next.js), Tailwind CSS, Node.js with Express, PostgreSQL on Supabase, Supabase Auth

## Setup
1. Clone the repo and check out the dev branch.
2. Copy backend/.env.example to backend/.env and fill in your Supabase URL and secret key.
3. Copy frontend/.env.example to frontend/.env.local.
4. Run database/schema.sql in the Supabase SQL Editor.
5. Seed sample data: cd backend, npm install, npm run seed
6. Frontend: cd frontend, npm install, npm run dev

## Branching
main (stable), dev (integration), feature/*, fix/*, hotfix/*.
Changes go in through pull requests with one review.
